# Release Notes

## [v2.0] - Viral Ready
### Added
- **One-Click Initialization**: Automated script `GhostShell.ps1` for role assignment (`Ghost` or `Shell`).
- **Sentinel Watchdog**: Background job ensuring Ollama and Docker R2D2 stay alive.
- **Surgical Cleanup**: 1.5B reasoning model intelligently prunes system bloatware.
- **Global Access**: Cloudflare Tunnel integration for exposing local endpoints securely.
- **Agent Integrations**: Automated deployment of OpenWebUI, OpenHands, and OpenClaw.
- **VS Code Sync**: Automated configuration of `~/.continue/config.json` for AI-assisted coding.

## [v1.0] - Foundation
### Added
- Proof of concept decoupling of Processing and Workspace nodes.
- Basic Ollama process execution and model fetching.
